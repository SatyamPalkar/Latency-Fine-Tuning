A reproducible baseline is not a speedup claim. The serial run measures warmed inference on one workstation; it does not establish production tail latency or multi-user capacity.

What the timings mean

  • Server TTFT observes the first generated token, before text buffering. Generation excludes model loading and prompt tokenization.
  • Client first text includes HTTP transport and word buffering. It is not token-level TTFT. Loopback does not represent Internet latency.
  • Greedy decoding, 32 requested output tokens, one CPU thread and a pinned model revision make the setup explicit. Token ranges and any failures remain in the artifacts.
  • p95 uses linear interpolation over successful observations. Thirty repetitions per case are exploratory; independent repetitions and controlled power/thermal conditions are needed for stronger claims.
  • The workstation was shared and power/thermal state was not controlled. No GPU, cold-start, concurrent-load or browser benchmarks are included here.
